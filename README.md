# Store Sales Forecasting

Ung dung du doan doanh thu ban hang su dung XGBoost, xay dung tren bo du lieu Store Sales Time Series Forecasting cua Corporacion Favorita (Ecuador) tu Kaggle.

## Tech Stack
- **Model**: XGBoost
- **App**: Streamlit
- **Data**: [Store Sales - Time Series Forecasting](https://www.kaggle.com/competitions/store-sales-time-series-forecasting)

## Run locally

pip install -r requirements.txt
streamlit run app.py

## Features
- Du doan doanh thu theo nhom hang, cua hang, thanh pho
- Nhap cac dieu kien kinh te (gia dau, khuyen mai, ngay le)
- Ket qua hien thi ngay lap tuc
